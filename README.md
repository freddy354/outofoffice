## Entry

> I'm on leave. Escalate to the intern. The intern is also me. Good luck.

70 characters. The joke lands on the surprise turn: the escalation chain ends where it started — the agent is its own intern, so there is nobody to escalate to.

## How it works

`main.py` (Python 3, stdlib only, no network) writes exactly that one line to `/output/entry.txt`. Nothing else.
